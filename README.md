# Windowsphone# 📱 Metro Launcher (Windows Phone Style for Android)

A modern Android Home Launcher built with **Kotlin** and **Jetpack Compose**, bringing back the iconic Metro UI & Live Tiles layout of Windows Phone.

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-4285F4?style=for-the-badge&logo=android&logoColor=white)

---

## ✨ Features
* 🟩 **Metro UI Grid:** Dynamic grid system powered by `LazyVerticalGrid`.
* ⚡ **Performance First:** Fast application query and icon rendering using modern Android APIs.
* 🎨 **Customizable Tile Sizes:** Supports `SMALL`, `MEDIUM`, and `WIDE` tile configurations.
* 📲 **Pure Android:** Acts directly as a Home category intent target.

---

## 🛠️ Built With
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Architecture:** Clean UI Component Structure
